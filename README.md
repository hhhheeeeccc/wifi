# 📡 WiFi Hotspot Pro

**تطبيق احترافي لمشاركة الإنترنت عبر نقطة اتصال WiFi**

نسخة مُحسّنة مع دعم بيئات الأمان المتقدمة، مصممة للعمل في بيئات تحتوي على **SentinelOne** وأنظمة حماية متقدمة أخرى.

---

## ✨ الميزات الجديدة (v2.2.0)

- 📱 **رمز QR للاتصال السريع**: توليد تلقائي لرمز QR يتيح للمتصلين الانضمام للشبكة فوراً دون كتابة كلمة المرور.
- 📂 **خادم مشاركة ملفات محلي**: شارك الملفات مع الأجهزة المتصلة عبر واجهة ويب بسيطة (HTTP) داخل الشبكة.
- 👥 **إدارة متقدمة للأجهزة (Blacklist)**: إمكانية حظر أجهزة محددة عبر عنوان MAC ومنعها من الوصول للإنترنت.
- 📋 **سجلات الاتصال (History)**: تتبع الأجهزة التي اتصلت بالشبكة مع تسجيل الوقت وعنوان IP و MAC.
- 🌐 **بوابة مصادقة (Captive Portal)**: صفحة ترحيبية تظهر للمستخدمين عند الاتصال.
- 🌍 **دعم اللغات (Multi-language)**: واجهة مستخدم تدعم اللغتين العربية والإنجليزية بشكل كامل.
- ⚙️ **توجيه المنافذ (Port Forwarding)**: دعم تحويل المنافذ للألعاب والتطبيقات المتقدمة.

---

## 🖼️ لقطات التطبيق المُحدثة

### 🏠 الواجهة الرئيسية
تتضمن حالة النظام والتحكم بالشبكة مع ميزة رمز QR السريع.

### 👥 إدارة الأجهزة
عرض تفصيلي لجميع المتصلين مع أزرار للحظر الفوري.

### 📂 مشاركة الملفات
مجلد محلي يمكنك وضع ملفاتك فيه ليتمكن المتصلون من تحميلها عبر المتصفح.

---

## 📋 المتطلبات

- **نظام التشغيل**: Windows 10 أو أحدث
- **الصلاحيات**: مسؤول (Administrator)
- **Node.js**: v14 أو أحدث

---

## 🚀 التثبيت والبناء

للمطورين:
```bash
npm install
# npm start
```

لبناء نسخة قابلة للتثبيت:
```bash
npm run build:installer
```

## 🔒 الأمان وتوافق SentinelOne

تم الحفاظ على المعايير الأمنية العالية:
- الاعتماد على **Windows WinRT APIs** الرسمية.
- عدم استخدام تعريفات (Drivers) خارجية قد تثير أنظمة الحماية.
- عزل تام للعمليات لضمان استقرار النظام.
